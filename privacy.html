Privacy policy

This application is a private Home Assistant integration used only by members of a single household.

What data is accessed

With the account holder's permission, the application accesses Google Calendar (and, where authorised, Google Drive) for the household's own Google account.

How it is used

Calendar data is used only to display, create and manage the household's events within its own Home Assistant system. Drive access, where granted, is used only to store that system's own backups.

Storage and sharing

Data is processed and stored only on the household's own Home Assistant server. It is not sold, shared with third parties, or used for advertising or any other purpose.

Revoking access

Access can be withdrawn at any time from the Google Account's security settings (Third-party apps with account access), or by removing the integration from Home Assistant.
